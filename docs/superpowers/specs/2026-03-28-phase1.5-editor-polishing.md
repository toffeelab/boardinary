# Phase 1.5 에디터 폴리싱 스펙

## 개요

Phase 1 코어 에디터의 UX를 개선한다. 패널 리사이즈/재배치, 노드 리사이즈, 그룹화/정렬, 연결선 검증, 드래그 미리보기를 추가.

## Content 스키마 버전

- **버전 유지: `version: 1`** — 새 필드(`width`, `height`, `parentId`)는 모두 optional이므로 기존 content와 하위 호환
- `migrateContent`에서 `group` 타입 노드가 있어도 정상 처리되도록 업데이트
- Phase 1 클라이언트가 Phase 1.5 content를 로드할 경우: group 노드는 unknown type으로 무시됨 (graceful fallback). 이는 허용되는 동작

## 구현 순서 (배치)

- **Batch A (레이아웃/UX)**: 패널 리사이즈(1) → 레이아웃 저장(2) → 패널 프리셋(3) → 드래그 노드 추가(7)
- **Batch B (그래프 구조)**: 노드 리사이즈(4) → 연결선 검증(6) → 그룹화/정렬(5)

Batch A 완료 후 체크포인트. Batch B는 content 스키마를 건드리므로 더 신중하게.

## 1. 패널 드래그 리사이즈

- 좌측 노드 목록, 우측 속성 패널의 **너비를 드래그로 조절**
- 패널 경계에 리사이즈 핸들 (hover 시 `col-resize` 커서)
- 최소 너비 180px, 최대 너비 400px
- 구현: `react-resizable-panels` 라이브러리 활용 (접근성, 키보드 리사이즈, min/max 내장)

## 2. 레이아웃 설정 저장

- 패널 너비, 프리셋, 노드 목록 토글 상태를 **localStorage**에 저장
- 페이지 로드 시 복원
- Zustand `persist` 미들웨어 활용 (`editor-store.ts` 확장)

## 3. 패널 재배치 (프리셋)

3가지 프리셋:

| 프리셋 | 좌측 | 우측 |
|--------|------|------|
| **기본** | 노드 목록 | 속성 패널 |
| **역배치** | 속성 패널 | 노드 목록 |
| **속성만** | (숨김) | 속성 패널 |

- 툴바 또는 에디터 상단에서 프리셋 토글
- 프리셋 선택도 localStorage에 저장

## 4. 노드 리사이즈 핸들

- @xyflow/react `NodeResizer` 컴포넌트 사용
- 4방향 + 4꼭짓점 핸들 (가로 + 세로 자유 리사이즈)
- 노드 선택 시에만 핸들 표시
- 최소 크기 제한: 120px x 60px
- 리사이즈도 Undo/Redo 히스토리에 포함
- 리사이즈 완료 시 자동 저장 트리거
- 리사이즈된 크기는 content jsonb의 노드 데이터에 `width`/`height` 필드로 저장

### Content 스키마 확장

```ts
interface StoryboardNode {
  id: string;
  type: "scene" | "event" | "branch";
  position: { x: number; y: number };
  width?: number;   // 리사이즈된 너비 (없으면 기본값)
  height?: number;  // 리사이즈된 높이 (없으면 기본값)
  data: StoryboardNodeData;
}
```

## 5. 그룹화

### 그룹 생성/해제
- **Ctrl+G**: 다중 선택된 노드를 그룹으로 묶기
- **Ctrl+Shift+G**: 그룹 해제

### 그룹 노드
- @xyflow/react의 parent node 기능 활용
- 노드 타입: `group` (기존 scene/event/branch에 추가)
- 반투명 배경 박스로 시각적 표현
- 그룹 라벨 편집 가능 (더블클릭 또는 속성 패널)
- 그룹 이동 시 내부 노드 함께 이동
- 그룹 삭제 시 내부 노드는 보존 (그룹만 해제, 절대 좌표로 변환)

### 그룹 동작 계약
- **자식 제약**: `extent: 'parent'` — 자식 노드는 그룹 영역 밖으로 드래그 불가
- **그룹 리사이즈**: 그룹 크기 줄일 때 자식이 영역 밖이면 리사이즈 거부 (최소 크기 = 자식 바운딩 박스)
- **좌표 변환 (Ctrl+G)**: 그룹 생성 시 선택 노드들의 바운딩 박스를 계산 → 그룹 위치 = 바운딩 박스 좌상단 - 패딩(20px). 자식 노드 위치 = 기존 절대 좌표 - 그룹 위치 (상대 좌표로 변환)
- **좌표 변환 (Ctrl+Shift+G)**: 그룹 해제 시 자식 노드 위치 = 그룹 위치 + 자식 상대 좌표 (절대 좌표로 복원). parentId 제거
- **중첩 그룹**: Phase 1.5에서는 금지 (그룹 내 그룹 불가). 추후 지원 가능
- **자식 탈착**: 드래그로 그룹 밖 이동 불가 (extent 제약). 명시적 그룹 해제만 가능

### Undo/Redo 통합
- **그룹 생성/해제**: 단일 스냅샷으로 처리 (그룹 노드 추가 + N개 자식 parentId 변경 + 좌표 변환을 하나의 undo 엔트리로)
- **정렬/분배**: 단일 스냅샷 (N개 노드 이동을 하나의 undo 엔트리로)
- **노드 리사이즈**: 리사이즈 완료(mouseup) 시 스냅샷 push

### Content 스키마 확장

```ts
// 그룹 노드도 nodes 배열에 포함
{
  id: "group-1",
  type: "group",
  position: { x: 50, y: 50 },
  width: 400,
  height: 300,
  data: { title: "1장: 시작" }
}

// 내부 노드는 parentId 참조
{
  id: "node-1",
  type: "scene",
  position: { x: 20, y: 40 },  // 그룹 내 상대 좌표
  parentId: "group-1",
  data: { ... }
}
```

### 정렬/분배
- 다중 선택 후 **우클릭 컨텍스트 메뉴**에서:
  - 좌 정렬 / 우 정렬 / 상 정렬 / 하 정렬
  - 가로 동일 간격 분배 / 세로 동일 간격 분배
- 정렬/분배도 Undo/Redo에 포함

## 6. 연결선 유효성 검증

### 검증 규칙
- **순환 참조 방지**: 엣지 연결 시 DFS로 사이클 감지 → 사이클이면 연결 거부
- **자기 자신 연결 방지**: source === target이면 거부
- **중복 연결 방지**: 동일 source → target 엣지가 이미 있으면 거부

### UX
- 연결 거부 시 토스트 알림 ("순환 참조가 발생합니다", "이미 연결되어 있습니다")
- `isValidConnection` prop 활용
- @xyflow/react의 `onConnect` 전에 `isValidConnection`에서 검증

## 7. 드래그 앤 드롭 노드 추가

### 기존 방식 유지
- 툴바 버튼 클릭 → 캔버스 중앙에 추가 (기존 동작)

### 새로운 방식 추가
- 툴바의 노드 타입 버튼을 **드래그 시작점**으로 활용
- 드래그 중: `onDragOver`에서 커서 위치를 `screenToFlowPosition`으로 변환, 플로팅 div로 미리보기 표시
- 캔버스 위에 드롭하면 해당 위치에 노드 생성
- @xyflow/react의 `onDragOver` + `onDrop` 이벤트 핸들러 + `screenToFlowPosition` 활용
- 툴바 버튼에 `draggable` + `onDragStart`로 노드 타입 전달 (`event.dataTransfer.setData`)
