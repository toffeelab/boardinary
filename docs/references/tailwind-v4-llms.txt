## v4 핵심 변경사항

### CSS-First 설정
v4에서는 JavaScript 설정 파일 대신 CSS 변수를 사용한다:

```css
@import "tailwindcss";

@theme {
  --color-brand: #3b82f6;
  --breakpoint-xs: 30rem;
  --breakpoint-3xl: 120rem;
}
```

@theme 내 CSS 변수가 자동으로 유틸리티 클래스를 생성한다.

### 반응형 디자인 (Mobile-First)

| 접두사 | 최소 너비 |
|--------|----------|
| sm     | 640px    |
| md     | 768px    |
| lg     | 1024px   |
| xl     | 1280px   |
| 2xl    | 1536px   |

```html
<div class="w-full md:w-1/2 lg:w-1/3">
  반응형 너비
</div>
```

### 다크 모드

기본: prefers-color-scheme 미디어 쿼리
클래스 기반:

```css
@import "tailwindcss";
@custom-variant dark (&:where(.dark, .dark *));
```

```html
<div class="bg-white dark:bg-gray-900">
  <h3 class="text-gray-900 dark:text-white">제목</h3>
  <p class="text-gray-500 dark:text-gray-400">본문</p>
</div>
```

### 주요 유틸리티 패턴
- Flexbox: flex, items-center, justify-between, gap-4
- Grid: grid, grid-cols-3, col-span-2
- 간격: p-4, m-2, space-y-4
- 타이포: text-sm, font-bold, leading-relaxed
- 색상: bg-blue-500, text-white, border-gray-200
- 상태: hover:bg-blue-600, focus:ring-2, disabled:opacity-50
